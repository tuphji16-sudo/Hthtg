# أثير | Atheer Social (Android Pro Edition) 💎🛡️

منصة تواصل اجتماعي عصرية وسريعة جداً بتصميم فريد يرتكز على **الخصوصية التامة، التشفير اللامركزي، وانعدام التتبع الإعلاني**، مهيأة كـ **تطبيق أندرويد حقيقي (PWA / WebAPK / APK)** مع جميع مزايا النسخة الاحترافية مفتوحة بالكامل.

---

## ✨ المميزات الرئيسية (Core Features)

### 1. 🛡️ الخصوصية والأمان الفائق (Zero-Trace & Privacy First)
* **تشفير ما بعد الكم (Kyber-1024):** حماية الاتصال ضد أي فك تشفير مستقبلي بواسطة الحوسبة الكمومية.
* **تشفير طرف لطرف (E2EE):** محادثات مشفرة بالكامل بدون أي خوادم وسيطة تسجل محتوى الرسائل.
* **وضع الشبح (Ghost Mode):** تصفح المحتوى والمنشورات دون تسجيل أي نشاط أو ظهور للمستخدمين الآخرين.
* **مسح الأثر الفوري (Panic Purge - Zero-Trace):** زر طوارئ لمسح كافة البيانات المحلية، المحادثات، والذاكرة المؤقتة بضغطة واحدة.
* **نزع بيانات الصور تلقائياً (EXIF Stripping):** إزالة إحداثيات GPS، نوع الكاميرا، والبيانات الوصفية قبل نشر أي صورة.

### 2. ⚡ أداء فائق وسرعة خارقة (High Performance)
* **واجهة مستخدم بدون إعلانات أو متتبعات:** زمن استجابة وعرض فوري (1.2ms) وتوفير كبير في استهلاك البيانات.
* **بنية React 19 + Vite فائقة الخفة.**

### 3. 📱 تطبيق أندرويد متكامل (Native Android Experience)
* **محاكي هاتف أندرويد 15:** شريط حالة حقيقي (5G+, Wi-Fi, البطارية, الساعة) وشريط تنقل بالإيماءات أو الأزرار.
* **قفل الشاشة البيومتري المدمج (In-Display Fingerprint):** قفل التطبيق فورياً مع محاكاة قراءة البصمة والاهتزاز اللمسي (Haptic Feedback) ورمز PIN احتياطي.
* **شبكة التواصل بدون إنترنت (Mesh P2P):** إرسال واستقبال الرسائل عبر الهواتف المجاورة باستخدام البلوتوث و Wi-Fi Direct.
* **مانع تصوير الشاشة (FLAG_SECURE):** حماية المحتوى الحساس من التقاط الشاشة أو تسجيل الفيديو.
* **تمويه أيقونة التطبيق (Stealth Icon Cloaking):** إمكانية تغيير شكل واسم التطبيق في شاشة الهاتف ليظهر كآلة حاسبة، تطبيق ملاحظات، أو ساعة منبه.
* **حزمة تثبيت APK و WebAPK:** تثبيت مباشر على الهاتف أو تنزيل ملف التثبيت المباشر.

## 🚀 التشغيل المحلي (Getting Started)

### المتطلبات:
* **Node.js** إصدار 18 أو أحدث
* **npm** أو **bun** أو **pnpm**

### خطوات التثبيت:

```bash
# 1. استنساخ المستودع (Clone Repository)
git clone https://github.com/<your-username>/atheer-social.git

# 2. الدخول لمجلد المشروع
cd atheer-social

# 3. تثبيت الحزم والمكتبات
npm install

# 4. تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:3000` أو المنفذ المحدد.
